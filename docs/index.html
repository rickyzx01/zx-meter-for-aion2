スキル内訳とバフ

スキルごとの与ダメージやクリティカル率を確認できます。DPS推移とバフの有効期間を同じ時間軸で表示し、維持率も確認できます。

HISTORY

戦闘履歴

終わった戦闘はPC内に保存します。履歴から戦闘や個人の詳細を開けます。アカウント登録は不要です。

INSTALL

インストール

ZIPの展開や.NETの追加インストールは不要です。

  1. 01

    EXEを実行する

    ダウンロードした ZXMeterForAION2.exe を実行し、Windowsの管理者確認を許可してください。

  2. 02

    AION2で戦闘を始める

    ゲーム内で戦闘に参加すると計測を始めます。プレイヤー行をクリックすると個人詳細が開きます。

HELP

使い方

更新するには？

最新版のEXEを実行してください。アンインストールは不要です。更新時には管理者確認が表示されます。現時点では、更新通知・自動更新には対応していません。

閉じた後、もう一度表示するには？

閉じるボタンはウィンドウを隠します。Windowsの通知領域にあるZX Meterのアイコンから再表示できます。表示アプリの終了も同じメニューから行えます。

自動起動を止めるには？

通知領域のメニューにある「Windows起動時に開始」をオフにします。次回以降の自動起動を止めます。オフでもEXEから手動で起動できます。

削除するには？

Windowsの「設定 → アプリ → インストールされているアプリ」から「ZX Meter for AION2」を削除してください。履歴と設定を残すか選べます。

不具合を見つけたら？

GitHubのIssuesに、使用したバージョン・発生時の操作・実際の動作を記載してください。
