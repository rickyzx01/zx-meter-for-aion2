現在は開発中です。ダウンロードはまだ公開していません。

ZX METER / AION2
01 / LIVE

視線を、戦闘に。

常駐ウィンドウにプレイヤー別のDPSと割合を表示。前面固定と縮小表示で、プレイ中に確認したい情報をコンパクトに。

02 / REVIEW

内訳まで、見渡す。

戦闘履歴からプレイヤーの詳細へ。スキルごとの与ダメージやクリティカル率を確認し、DPS推移とバフの有効期間・維持率を見比べられます。

03 / LOCAL

記録は、このPCに。

戦闘の記録と解析はPC内で完結。終了した戦闘は履歴に保存され、後から振り返れます。利用者のアカウント登録は不要です。

GET STARTED

EXEひとつで、始める。

配布開始後の導入手順です。
ZIPの展開や.NETの追加インストールは不要。

  1. 01

    ダウンロードして実行

    配布EXEを起動し、Windowsの管理者確認を許可します。

  2. 02

    ゲームを起動

    受信サービスと表示アプリを導入します。ゲーム内で戦闘に参加すると計測します。

  3. 03

    次からは、自動で起動

    Windowsにログインすると表示アプリが起動します。自動起動は通知領域のメニューから変更できます。

SUPPORT

使う前に。

更新するには？

最新版のEXEを実行してください。アンインストールは不要です。更新時には管理者確認が表示されます。現時点では、更新通知・自動更新には対応していません。

閉じた後、もう一度表示するには？

閉じるボタンはウィンドウを隠します。Windowsの通知領域にあるZX Meterのアイコンから再表示できます。表示アプリの終了も同じメニューから行えます。

自動起動を止めるには？

通知領域のメニューにある「Windows起動時に開始」をオフにします。次回以降の自動起動を止めます。オフでもEXEから手動で起動できます。

削除するには？

Windowsの「設定 → アプリ → インストールされているアプリ」から「ZX Meter for AION2」を削除してください。履歴と設定を残すか選べます。
