# <img src="assets/icon.svg" width="36" height="36" align="absmiddle" alt=""> ZX Meter for AION2

AION2用のDPSメーターです。戦闘中のDPSを表示し、戦闘後にスキル内訳やバフの維持率を確認できます。

[Windows版をダウンロード](https://github.com/rickyzx01/zx-meter-releases/releases/latest) · [更新履歴](https://github.com/rickyzx01/zx-meter-releases/releases)

Windows 10 / 11（64ビット）対応。

## 機能

- プレイヤー別のDPS・与ダメージ・ダメージ割合を表示
- 戦闘履歴と、プレイヤー別・スキル別の内訳を表示
- DPS推移とバフの有効期間・維持率を表示
- カカシの60秒計測と手動停止
- 前面固定、透明度、自動起動の切り替え

戦闘の記録と解析はPC内で行います。

## インストール

ダウンロードしたEXEを実行し、Windowsの管理者確認を許可してください。

インストール後は自動で起動します。

## 基本操作

- プレイヤー行をクリックすると個人詳細が開きます。
- 履歴から過去の戦闘を開けます。
- 閉じるボタンはウィンドウを隠します。Windowsの通知領域にあるZX Meterのアイコンから再表示できます。
- 自動起動は、通知領域のメニューの「Windows起動時に開始」で変更します。
- 常駐ウィンドウの透明度も、通知領域のメニューから変更できます。
- 表示アプリを終了する場合も、通知領域のメニューを使います。
