# ZX Meter for AION2

AION2の戦闘を振り返るためのDPSメーター。

**現在は開発中です。ダウンロードはまだ公開していません。**

## できること

- 戦闘中のDPSを、小さな常駐ウィンドウで確認。
- 戦闘履歴から、プレイヤー別・スキル別の与ダメージを確認。
- DPS推移とバフの有効期間・維持率を確認。

## 導入

Windows 10 / 11の64ビット版向けです。

配布開始後は、`ZX Meter for AION2.exe` をダウンロードして実行してください。初回の管理者確認後、必要なものをまとめて導入します。ZIPの展開や.NETの追加インストールは不要です。

## 起動と終了

PC起動時に受信サービスが、Windowsログイン時に表示アプリが起動します。通知領域のアイコンから、自動起動のオン・オフを変更できます。

ウィンドウの閉じるボタンは表示を隠します。表示アプリを終了する場合は、通知領域のメニューを使ってください。

## 更新

最新版のEXEを実行してください。アンインストールは不要です。更新時には管理者確認が表示されます。

現在、アプリによる更新通知・自動更新はありません。

## アンインストール

Windowsの「設定 → アプリ → インストールされているアプリ → ZX Meter for AION2」から削除できます。履歴と設定を残すか選べます。

## データ

戦闘の記録と解析は利用者のPC内で行います。戦闘履歴を見るためのアカウント登録は不要です。
