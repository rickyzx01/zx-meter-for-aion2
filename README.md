# ZX Meter for AION2

AION2用のDPSメーターです。戦闘中のDPSを表示し、戦闘後にスキル内訳やバフの維持率を確認できます。

[Windows版をダウンロード](https://github.com/rickyzx01/zx-meter-releases/releases/latest/download/ZXMeterForAION2.exe) · [使い方](https://rickyzx01.github.io/zx-meter-releases/) · [更新履歴](https://github.com/rickyzx01/zx-meter-releases/releases)

Windows 10 / 11（64ビット）対応。

## 機能

- プレイヤー別のDPS・与ダメージ・ダメージ割合を表示
- 戦闘履歴と、プレイヤー別・スキル別の内訳を表示
- DPS推移とバフの有効期間・維持率を表示
- カカシの60秒計測と手動停止
- 前面固定、縮小表示、自動起動の切り替え

戦闘の記録と解析はPC内で行います。アカウント登録は不要です。

## インストール

`ZXMeterForAION2.exe` をダウンロードして実行し、Windowsの管理者確認を許可してください。ZIPの展開や.NETの追加インストールは不要です。

導入後はPC起動時に受信サービスが、Windowsへのログイン時に表示アプリが起動します。ゲーム内で戦闘に参加すると計測を始めます。

## 基本操作

- プレイヤー行をクリックすると個人詳細が開きます。
- 履歴から過去の戦闘を開けます。
- 閉じるボタンはウィンドウを隠します。Windowsの通知領域にあるZX Meterのアイコンから再表示できます。
- 自動起動は、通知領域のメニューの「Windows起動時に開始」で変更します。
- 表示アプリを終了する場合も、通知領域のメニューを使います。

## 更新

最新版の `ZXMeterForAION2.exe` を実行してください。更新時に管理者確認が表示されます。アンインストールは不要です。

更新通知・自動更新には対応していません。新版は[更新履歴](https://github.com/rickyzx01/zx-meter-releases/releases)から確認してください。

## アンインストール

Windowsの「設定 → アプリ → インストールされているアプリ」から「ZX Meter for AION2」を削除してください。履歴と設定を残すか選べます。
