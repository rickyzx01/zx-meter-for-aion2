# <img src="assets/icon.svg" width="36" height="36" align="absmiddle" alt=""> ZX Meter for AION2

AION2用のDPSメーターです。戦闘中のDPSを表示し、戦闘後にスキル内訳やバフの維持率を確認できます。

## 機能

- プレイヤー別のDPS・与ダメージ・被ダメージ・与ヒールを表示
- 戦闘履歴と、プレイヤー別・スキル別の内訳を表示
- DPS推移とバフの有効期間・維持率を表示
- カカシの60秒計測と手動停止
- 前面固定、透明度、自動起動の切り替え

戦闘の記録と解析はPC内で行います。

## ダウンロード

[Windows版をダウンロード](https://github.com/rickyzx01/zx-meter-for-aion2/releases/latest) · [更新履歴](https://github.com/rickyzx01/zx-meter-for-aion2/releases)

Windows 10 / 11（64ビット）対応。

## インストール

ダウンロードしたインストーラーを開き、自動起動の有無を選んで「インストール」を押してください。Windowsの管理者確認を許可するとインストールが始まります。

デスクトップに作成されたアイコンから起動できます。停止している計測処理を起動し、起動済みならメーターを表示します。

完了画面の「起動」でメーターが開きます。自動起動を有効にした場合は、次回からWindowsログイン時にも起動します。

## 基本操作

- プレイヤー行をクリックすると個人詳細が開きます。
- 右上の <img src="assets/history.png" width="18" height="18" alt="履歴">（履歴）を押すと、過去の戦闘を開けます。
- 閉じるボタンはウィンドウを隠します。Windowsの通知領域にあるZX Meterのアイコンから再表示できます。
- 自動起動は、メーターの歯車から設定を開き、「Windowsログイン時に起動」で変更します。
- 履歴の左にある <img src="assets/transparency.png" width="18" height="18" alt="透明度"> で透過のオン／オフを切り替えます。半透明のときはアイコンが光ります。
- 受信・解析・表示をすべて終了するには、通知領域のアイコンを右クリックして「終了」を選びます。

## 更新

最新版のEXEを開き、「更新」を押すとインストール済みのアプリが更新されます。履歴と設定は引き継がれます。



## アンインストール

通常のアプリと同様に、Windowsの設定からアンインストールできます。
