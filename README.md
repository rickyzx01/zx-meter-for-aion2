# <img src="assets/icon.svg" width="36" height="36" align="absmiddle" alt=""> ZX Meter for AION2

AION2用のDPSメーターです。プレイヤーごとのDPS・与ダメージ・被ダメージ・与ヒールを計測できます。

プレイヤー詳細では、スキルごとのダメージ内訳や各種バフの維持率と有効時間、発動区間別のDPSが見られます。

戦闘は自動で記録され、履歴からいつでも開けます。カカシ計測は60秒で自動停止するため、計測時間を揃えて結果を比較できます。

カカシ計測の手動停止や、前面固定・半透明表示・Windows起動時の自動起動にも対応しています。

記録・解析・保存はすべて自分のPC内で完結し、外部への通信やデータ保存は行いません。

## ダウンロード

[リリースページ](https://github.com/rickyzx01/zx-meter-releases/releases/latest) · Windows 10 / 11（64ビット）

## インストール

1. インストーラーを実行し、管理者確認で「はい」を選択します。
2. 完了するとメーターが起動します。次回からはデスクトップのアイコンで起動できます。

管理者確認は、計測用サービスをWindowsに登録するために必要です。

「WindowsによってPCが保護されました」と表示された場合は、「詳細情報」→「実行」を選択します。

## 基本操作

- プレイヤー行：個人詳細を開く
- <img src="assets/history.png" width="18" height="18" alt="履歴"> 履歴：過去の戦闘を開く
- <img src="assets/transparency.png" width="18" height="18" alt="透明度"> 透過：半透明のオン／オフ。オンのときはアイコンが光ります。

×ボタンはウィンドウを隠します。再表示・自動起動の切り替え・表示アプリの終了は、Windowsの通知領域にあるZX Meterのメニューから行えます。
